# Ошибки в сербском: классы, проверки, процесс

Зачем этот файл. Сербский пишет модель, а не носитель, и вычитка той же моделью
повторяет её слепые зоны. Поэтому качество держится не на «аккуратности», а на
трёх вещах: внешний источник правды вместо памяти, автоматические проверки и
регистр ошибок, в котором каждая найденная ошибка превращается в правило.

**100% гарантии нет и быть не может**: словарь и Wiktionary не заменяют носителя.
Ниже честно записано, что ловится машиной, а что — только глазами.

## Как это устроено

| Слой | Что | Где |
|---|---|---|
| Источник правды | Hunspell-словарь сербского (LibreOffice, sr-Latn), Wiktionary (ударения), `docs/GRAMMAR.md` | `scripts/.cache/` (скачивается сам) |
| Автопроверки | орфография, экавица, алфавиты, диакритика; ударения; транскрипции; лексика; структура заданий | `make lint-sr`, `make test`, `check_transcriptions.py` |
| Регистр | этот файл: класс ошибки → как ловим → пример | `docs/SERBIAN_ERRORS.md` |
| Очередь на носителя | то, что машина проверить не может | `docs/stress-queue.md` |

Команды:

```bash
pip3 install spylls pyyaml     # один раз
make lint-sr                   # орфография/экавица/алфавиты + отчёт по ударениям
python3 scripts/lint_serbian.py --lesson 49        # один урок
python3 scripts/lint_serbian.py --prose            # + Latin в `explain` (шумно)
python3 scripts/check_stress.py --write-queue      # обновить docs/stress-queue.md
python3 scripts/check_transcriptions.py            # транскрипции
make test                                          # гарды контента (Go)
```

## Классы ошибок

«Авто» — поймает машина; «глаза» — только вычитка. Примеры реальные.

### Написание

| ID | Класс | Как ловим | Пример |
|---|---|---|---|
| O1 | Опечатка / несуществующее слово | авто: `lint_serbian.py` (SPELL) | `kuča` вместо `kuća`, `centrru` |
| O2 | Забытая диакритика, получилось другое слово | авто: `lint_serbian.py` (DIAC): слово без диакритики, у которого «двойник» с ć/č/š/ž/đ тоже слово, требует подтверждения в `diac_ok` | `skoli` вместо `školi` |
| O3 | Латиница и кириллица в одном слове (омоглифы) | авто: `lint_serbian.py` (SCRIPT) в упражнениях, чтении, репликах, словаре и код-спанах теории; в транскрипциях — `check_transcriptions.py`. До 2026-10-13 код-спан теории с кириллицей пропускался целиком — дыру нашла мутация при работе над уроком 60 | кириллическая `о` внутри `autobusоm` (нашли на ревью уровня 3) |
| O4 | Кириллица словаря расходится с латиницей | авто: `lint_serbian.py` (CYR): `cyrillic` в `vocab.yaml` = транслит `latin` (озвучка идёт из этого поля) | неверная кириллица в словаре (ревью 2026-10-05) |

### Норма (экавица, Сербия)

| ID | Класс | Как ловим | Пример |
|---|---|---|---|
| E1 | Иекавизм или хорватизм в курсе по экавице | авто: `lint_serbian.py` (YAT): эвристика `ije/je → e` + чёрный список в `content/lint-serbian.yaml` | `lijepo`, `vrijeme`, `tisuća`, `kruh`, `tko` |

Чёрный список в `croatisms:` пополняем только тем, в чём уверены: ложное
срабатывание хуже пропуска (так, `grah` оттуда пришлось убрать).

### Ударение и транскрипция

| ID | Класс | Как ловим | Пример |
|---|---|---|---|
| S1 | Неверное место ударения | частично авто: `check_stress.py` сверяет одиночные леммы словаря с Wiktionary, `check_stress_tokens.py` — каждое слово из транскрипций (уровень A, нисходящее ударение, останавливает `make lint-sr`; уровень B, восходящее, только отчёт). Формы без своей статьи (`godinu`) проверить нечем. Остальное — только носитель | `jabuka`: в курсе `ябу́ка`, верно `я́бука`; `godina`, `bolestan`, `slobodan`, `zajedno` и ещё 6 слов стояли на втором слоге в 24 местах (найдено 2026-10-14) |
| S2 | Ударение на последнем слоге, на клитике, больше одного ударения | авто: `check_transcriptions.py` | |
| S3 | Транскрипция не по правилам движка (`e→э`, `đ→дьжь`, `ji→йи`) | авто: `check_transcriptions.py` + `translit_ru.py` | |

**S1 — самый слабый класс.** При первой же сверке 49 из 312 сравнимых слов
(16%) разошлись с Wiktionary; для 10 из них расхождение почти наверняка
ошибка курса (нисходящее ударение, не зависящее от сербской/хорватской нормы),
в 35 случаях ударение в курсе на слог позже. Это системная привычка ставить
ударение на второй слог. Разбор — `docs/stress-queue.md`. Ударения **форм**
(не лемм) и фраз не проверяются вообще.

## Что НЕ ловится ничем

Честный список, чтобы не было иллюзии покрытия:

- Смысловые и методические ошибки (M1–M3, X2–X4) — только вычитка.
- Ударения форм и фраз; тон и долгота; сербские варианты там, где Wiktionary
  следует хорватской норме (уровень B в `docs/stress-queue.md`).
- Стиль и естественность: фраза может быть грамматически верной и звучать
  по-книжному. Это может оценить только носитель.

## Процесс: что делать с найденной ошибкой

1. **Исправь** ошибку в контенте (транскрипцию — через `translit_ru.py`;
   изменился произносимый текст — перегенерируй озвучку).
2. **Классифицируй** по таблице. Нового класса нет — заведи строку (ID, как
   ловить, пример).
3. **Закрой класс**, если можно: правило в `lint_serbian.py` /
   `content/lint-serbian.yaml`, новая проверка в `check_transcriptions.py` или
   Go-гард. Нельзя — запиши в «глаза» и добавь пункт в чеклист ревью.
4. **Проверь, что гард ловит**: внеси ошибку в копию контента и запусти
   `python3 scripts/lint_serbian.py --content <копия>` (так проверялась DIAC).
5. Исключения (`allow`, `allow_in`, `yat_ok`, `diac_ok`) — только с причиной;
   линтер не стартует с пустой.

## Правила работы Claude с сербским

1. **Не писать формы по памяти и аналогии.** Новое слово или форма — сначала
   `vocab.yaml`/`docs/GRAMMAR.md`, потом `make lint-sr`.
2. **Ударение берётся из источника**, а не ставится «на глаз»: лемма из
   Wiktionary (`check_stress.py`), нет данных или Wiktionary и курс спорят —
   слово идёт в `docs/stress-queue.md`, а не в курс «как показалось».
3. **Не говорить «проверено» без запуска.** Прогнал `make lint-sr` — показал
   вывод и честно сказал, чем проверено (словарь) и чем нет (смысл, ударения
   форм, естественность).
4. **Сомнительное выносить списком**, а не проглатывать. Гриша не носитель, но
   может отдать список репетитору или в сербский источник.
5. Каждую сербскую фразу в чате сопровождать русским переводом (`serbian-always-translate`).
6. Менял произносимый текст — перегенерировать озвучку (`tts.py --force --only <id>`).
7. Нашёл ошибку — пройти «Процесс» выше, а не только исправить.
