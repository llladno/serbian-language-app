# Грамматика курса — справочник

Единое место, куда сведены грамматические правила, реально преподаваемые в
`content/lessons/00–29`. Цель — не переизобретать и не перепроверять одно и
то же в каждом новом уроке/упражнении: если правило уже здесь, бери его
отсюда как источник истины для этого курса.

**Уровень уверенности.** Правила и формы ниже прогнаны через (1) движок
`scripts/check_transcriptions.py` (только формат транскрипций, не смысл),
(2) пять независимых вычиток контента (модель+агенты, без сверки со
словарём/носителем) и (3) точечные исправления найденных противоречий. Это
даёт высокую, но не 100% уверенность — особенно для **ударений**: сербская
акцентуация не выводится из правил, только из словаря/носителя, и её
никто здесь не проверял на 100%. Морфология (формы, падежи, согласование)
проверена надёжнее, чем место ударения. При сомнении — смотри примеры,
которые уже прошли проверку в `content/vocab.yaml`/`content/grammar.yaml`,
не выдумывай новые формы по аналогии вслепую.

Соответствующие SRS-карточки (для регулярного повторения самим приложением)
— `content/grammar.yaml`. Этот файл — более полный текстовый справочник,
`grammar.yaml` — их краткая выжимка под карточки.

## 1. Глагол «быть» — `jesam` (урок 04)

| | форма |
|---|---|
| ja | `sam` |
| ti | `si` |
| on/ona/ono | `je` |
| mi | `smo` |
| vi | `ste` |
| oni/one/ona | `su` |

Отрицание — отдельные формы: `nisam, nisi, nije, nismo, niste, nisu`.

`je`/`su`/`si`/`smo`/`ste` (кроме `sam` в начале фразы) — клитики, стоят
на **втором месте** во фразе, безударны в потоке речи.

Частая ошибка новичка — пропуск связки: **`Iz Rusije.`** вместо
`Ja sam iz Rusije.` В сербском (в отличие от русского) связка в настоящем
времени обязательна.

## 2. `imati` / `nemati` — «иметь» / «не иметь» (урок 06)

| | imati | nemati |
|---|---|---|
| ja | `imam` | `nemam` |
| ti | `imaš` | `nemaš` |
| on/ona/ono | `ima` | `nema` |
| mi | `imamo` | `nemamo` |
| vi | `imate` | `nemate` |
| oni/one/ona | `imaju` | `nemaju` |

`nemati` — не отрицательная частица + `imati`, а **отдельный глагол** со
своим спряжением.

### Аккузатив прямого дополнения после `imam`/`nemam`

- Мужской род, **одушевлённый**: аккузатив = генитив (доп. `-a`):
  `brat → brata`, `sin → sina`, `muž → muža`.
  `Imam brata.` / `Nemam brata.`
- Мужской род, **неодушевлённый**: аккузатив = именительный (без
  изменений): `sat → sat`, `orman → orman`.
- Женский род на `-a`: аккузатив на `-u`: `sestra → sestru`,
  `žena → ženu`, `ćerka → ćerku`.

## 3. Притяжательные `moj`/`tvoj`/`njegov`/`njen` — согласование по роду (урок 07)

Притяжательное согласуется с родом **предмета обладания**, не с полом
говорящего:

- `moj tata` (m), `moja mama` (f), `moje dete` (n)
- то же для `tvoj/tvoja/tvoje`, `njegov/njegova/njegovo`,
  `njen/njena/njeno`

Частая ошибка — не согласовали род: `moj mama` (неверно) →
`moja mama` (верно); `tvoja brat` (неверно) → `tvoj brat` (верно).

## 4. Презент — три типа спряжения (урок 16)

Тип виден по форме «я» (`ja`):

| | **-am** | **-im** | **-em** |
|---|---|---|---|
| ja | čitam | radim | pišem |
| ti | čitaš | radiš | pišeš |
| on/ona/ono | čita | radi | piše |
| mi | čitamo | radimo | pišemo |
| vi | čitate | radite | pišete |
| oni/one/ona | čitaju | rade | pišu |

- **-am**: `znati, gledati, slušati, čitati…`
- **-im**: `živeti, govoriti, učiti, misliti, raditi…`
- **-em**: `pisati, razumeti → razumem, ići → idem` (неправильные по
  основе)
- Отдельно: глаголы на `-ovati`/`-ivati` спрягаются с инфиксом `-uje-`,
  это тоже фактически тип `-em`: `doručkovati → doručkujem`,
  `putovati → putujem`, `kupovati → kupujem`, `stanovati → stanujem`.
  **Не** путать с типом `-am` — на письме `doručkovati` заканчивается на
  `-ovati`, но спрягается НЕ как `doručkovam` (в контенте уже была такая
  ошибка, исправлена).

Личное местоимение (`ja`, `ti`…) обычно опускают — форма глагола и так
однозначна.

## 5. Число + существительное — паукальные формы (урок 08)

| Число | Форма | Примеры |
|---|---|---|
| **1** (…21, …31) | как в словаре (именительный) | `jedan dinar`, `jedna kafa`, `jedna godina` |
| **2, 3, 4** | «двойка»: `-a`/`-e` | `dva dinara`, `tri kafe`, `četiri godine` |
| **5 и больше** | «мешок»: обычно `-a` | `pet dinara`, `deset kafa`, `sto godina` |

Работает по аналогии с русским «один рубль / два рубля / пять рублей».
Частая ошибка — использовать форму 5+ после 2–4 или наоборот
(`pet dinar` вместо `pet dinara`; `dve kafa` вместо `dve kafe`).

### Частный случай — возраст (`godina`, урок 09)

`Imam ... godinu / godine / godina` по той же паукальной логике:
- 1 год → `Imam jednu godinu.`
- 2–4 → `Imam dve/tri/četiri godine.`
- 5+ → `Imam trideset godina.`

## 6. Прилагательные, согласующиеся по роду с говорящим (уроки 21–22)

`gladan`(m) / `gladna`(f) — «голоден/голодна»;
`žedan`(m) / `žedna`(f) — «хочет пить».

Согласуются с полом того, о ком говорят, а не с грамматическим родом
существительного — частая ошибка, если не думать про пол говорящего:
женщина должна сказать `Gladna sam.`, не `Gladan sam.`

## 7. `u` / `na` — предлоги места + генитив после `nema` (урок 19)

- `u` — «внутри»: `u sobi`, `u kući`, `u gradu`, `u stanu`
- `na` — «на поверхности», а также по традиции у части мест:
  `na stolu`, `na poslu`, `na fakultetu`, `na terasi`

### Генитив после `nema`

После `nema` (нет — и в личных, и в безличных конструкциях) существительное
идёт в **родительном падеже**, часто просто `+ -a`:

- `nema lifta` (нет лифта), `nema tuša` (нет душа)
- `Zgrada nema lifta.` (в доме нет лифта) — **не** `Zgrada nema lift.`
- `Nemam ormana u sobi.` — **не** `Nemam orman u sobi.`

(В контенте раньше была именно эта ошибка — теория одновременно учила
правилу и нарушала его в своих же примерах; исправлено.)

## 8. Вопросительные слова (урок 23)

| Сербский | Русский |
|---|---|
| `ko` | кто |
| `šta` | что |
| `gde` | где |
| `kuda` | куда |
| `odakle` | откуда |
| `kada` / `kad` | когда |
| `kako` | как |
| `koliko` | сколько |

**`šta` vs `što`:** «что» (вопрос) = `šta`, не `što`. Сам по себе `što`
«что» не значит — входит в `zato što` (потому что) или служит союзным
словом «который». Не путать одно с другим.

**Да/нет-вопрос:** `Da li imate vodu?` (литературно) /
`Jel' imate vodu?` (разговорно). `li` — клитика, никогда не в начале
фразы.

### `koji` / `kakav` / `čiji` — три «какой» (урок 23)

Разные вопросы, каждый меняется по роду (m/f/n):

| | вопрос | пример |
|---|---|---|
| `koji`/`koja`/`koje` | который (из ряда, выбор) | `Koji autobus ide u centar?` |
| `kakav`/`kakva`/`kakvo` | какой (по качеству/свойству) | `Kakvo je vreme?` |
| `čiji`/`čija`/`čije` | чей | `Čiji je ovo ključ?` |

`koji` спрашивает выбор из известных вариантов, `kakav` — свойство.
Частая ошибка — спросить `Koji je vreme?` вместо `Kakvo je vreme?`
(вопрос о свойстве, не о выборе; к тому же `vreme` среднего рода).

## 9. `volim da` / `moram da` — глагол + `da` + глагол (урок 17)

`volim`/`moram`/`hoću`/`moći` и т.п. + `da` + спрягаемый (не
инфинитив!) второй глагол:

- `Volim da čitam.` (я люблю читать) — **не** `Volim čitam.`
- `Moram da idem.` (мне надо идти) — **не** `Moram idem.`

Частая ошибка новичка — пропустить `da` или оставить второй глагол в
словарной форме.

## 10. `sviđa mi se` — дательный падеж местоимений (урок 27)

Конструкция безличная, буквально «нравится мне»: подлежащее — то, что
нравится, а «мне/тебе/…» — краткая форма дательного падежа местоимения:

| Полная форма | Краткая (используется в `sviđa ... se`) |
|---|---|
| meni | `mi` |
| tebi | `ti` |
| njemu | `mu` |
| njoj | `joj` |
| nama | `nam` |
| vama | `vam` |
| njima | `im` |

`Sviđa mi se leto.` (мне нравится лето). Во множественном числе того,
что нравится, — `Sviđaju mi se planine.` Частая ошибка — забыть
возвратное `se`: `Sviđa mi leto.` (неверно) → `Sviđa mi se leto.`

## 11. `zašto` / `zato što` / `jer` (урок 24)

- `Zašto?` — «почему?» (вопрос)
- `zato što` — «потому что» (полный союз)
- `jer` — «потому что» (короче, разговорнее)
- голый `što` сам по себе не значит «потому что» (см. §8)

## 12. Этажи — смещение на единицу (урок 18)

В сербском счёт этажей **не включает первый (наземный) этаж** отдельно —
`prvi sprat` (первый «спрат») соответствует русскому **второму** этажу,
`drugi sprat` — третьему, и так далее. При переводе этажей всегда сдвигай
на +1 в русскую сторону.

## Как этим пользоваться

- Перед тем как писать новое упражнение на грамматическую точку — сверься
  с этой таблицей, а не выводи форму по памяти заново.
- Если правила здесь нет — не изобретай его, проверь по вокабуляру
  (`content/vocab.yaml`, поле `note` у глаголов часто содержит тип
  спряжения) или явно пометь как «нужна проверка носителем».
- Нашёл ошибку в этом файле или расхождение с `content/` — правь сразу оба
  места и прогоняй `python3 scripts/check_transcriptions.py` +
  `go test ./server/internal/content/...`.
