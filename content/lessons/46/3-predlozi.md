## Предлоги + родительный

Эти предлоги всегда ведут за собой родительный:

| предлог | значение | пример |
|---|---|---|
| `iz` | из | `iz Rusije` [из Ру́сие], `iz grada` [из гра́да] |
| `do` | до | `do stanice` [до ста́ницэ], `do centra` [до цэ́нтра] |
| `od` | от, с | `od sestre` [од сэ́стрэ], `od ponedeljka do petka` [од понэ́дэлька до пэ́тка] |
| `kod` | у (кого), «дома у» | `kod lekara` [код лэ́кара], `kod kuće` [код ку́чэ] *(дома)* |
| `bez` | без | `kafa bez šećera` [ка́фа бэз шэ́чэра], `čaj bez mleka` [чай бэз млэ́ка] |
| `pored`, `blizu` | рядом, около | `pored banke` [по́рэд ба́нкэ], `blizu parka` [бли́зу па́рка] |
| `iza`, `ispred` | позади, перед | `iza kuće` [и́за ку́чэ], `ispred škole` [и́спрэд шко́лэ] |
| `preko puta` | напротив | `preko puta pošte` [прэ́ко пу́та по́штэ] |
| `posle`, `pre` | после, до | `posle posla` [по́слэ по́сла], `pre doručka` [прэ до́ручка] |
| `zbog` | из-за | `zbog posla` [због по́сла] |

Дни недели в родительном — тот же приём: `od ponedeljka do petka` [од понэ́дэлька до пэ́тка] *(с понедельника по пятницу)*, `od subote do nedelje` [од су́ботэ до нэ́дэле].

> Помнишь «где банк?» из урока про город: `Pored banke, preko puta pošte.` [По́рэд ба́нкэ, прэ́ко пу́та по́штэ.] — это два родительных подряд.
