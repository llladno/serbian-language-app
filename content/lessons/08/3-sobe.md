## Комнаты

| Сербский | Русский |
|---|---|
| `soba` *(соба)* | комната |
| `kuhinja` *(кухиња)* | кухня |
| `kupatilo` *(купатило)* | ванная / туалет (обычно вместе) |
| `spavaća soba` *(спаваћа соба)* | спальня |
| `dnevni boravak` *(дневни боравак)* | гостиная |
| `hodnik` *(ходник)* | коридор, прихожая |
| `terasa` / `balkon` *(тераса / балкон)* | терраса / балкон |

- `Stan ima dve sobe.` *(стан има две собе — в квартире две комнаты)*
- `Kuhinja je mala, a dnevni boravak velik.` *(кухня маленькая, а
  гостиная большая)*

> «однушка / двушка» по-сербски — `garsonjera` / `dvosoban stan`.
