## Вещи в доме

| Сербский | Русский |
|---|---|
| `sto` *(сто)* | стол *(род. `stola`; не путать со «sto» = 100)* |
| `stolica` *(столица)* | стул *(⚠️ не «столица» — это `prestonica`)* |
| `krevet` *(кревет)* | кровать |
| `orman` *(орман)* | шкаф |
| `frižider` *(фрижидер)* | холодильник |
| `šporet` *(шпорет)* | плита |
| `sudopera` *(судопера)* | раковина (кухонная) |
| `lampa` *(лампа)* | лампа |
| `polica` *(полица)* | полка |
| `ogledalo` *(огледало)* | зеркало |

- `Na stolu je lampa.` *(на столу је лампа — на столе лампа)*
- `Frižider je nov.` *(фрижидер је нов — холодильник новый)*
