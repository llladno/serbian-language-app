## Напитки

| Сербский | Русский |
|---|---|
| `voda` *(вода)* | вода *(`gazirana` / `negazirana` — с газом / без)* |
| `kafa` *(кафа)* | кофе |
| `čaj` *(чај)* | чай |
| `sok` *(сок)* | сок |
| `pivo` *(пиво)* | пиво |
| `vino` *(вино)* | вино *(`crno` / `belo` — красное / белое)* |
| `rakija` *(ракија)* | ракия — фруктовая водка, сербский аперитив |

- `Jednu kafu, molim.` *(једну кафу — один кофе, пожалуйста)*
- `Za mene sok.` *(за мене — мне сок)*
- `Još jedno pivo.` *(још једно — ещё одно пиво)*
