## У меня есть / нет — imam / nemam

- **imam** *(имам — у меня есть)*
- **nemam** *(немам — у меня нет)*

После них слово чуть меняет окончание (винительный / родительный
падеж). Пока запоминай готовыми формами:

| в словаре | после imam / nemam |
|---|---|
| brat | **Imam brata.** *(у меня есть брат)* |
| sestra | **Imam sestru.** |
| muž | **Imam muža.** |
| žena | **Imam ženu.** |
| sin | **Imam sina.** |
| ćerka | **Imam ćerku.** |
| dete → deca | **Nemam decu.** *(детей нет)* |

`mama`, `tata` тоже меняются: **Imam mamu i tatu.**
