## Родительный множественного — самые частые формы

Выучи как готовые «пакеты» к числам от пяти:

| слово | форма | пример |
|---|---|---|
| `dinar` [ди́нар] | `dinara` [ди́нара] | `pet dinara` [пэт ди́нара] |
| `minut` [ми́нут] | `minuta` [ми́нута] | `petnaest minuta` [пэ́тнаэст ми́нута] |
| `sat` [сат] | `sati` [са́ти] | `pet sati` [пэт са́ти] |
| `dan` [дан] | `dana` [да́на] | `dvadeset dana` [два́дэсэт да́на] |
| `godina` [годи́на] | `godina` [годи́на] | `trideset godina` [три́дэсэт годи́на] |
| `put` [пут] | `puta` [пу́та] | `pet puta` [пэт пу́та] *(пять раз)* |
| `kuća` [ку́ча] | `kuća` [ку́ча] | `pet kuća` [пэт ку́ча] |
| `knjiga` [кни́га] | `knjiga` [кни́га] | `mnogo knjiga` [мно́го кни́га] |
| `sestra` [сэ́стра] | `sestara` [сэ́стара] | `pet sestara` [пэт сэ́стара] |
| `stan` [стан] | `stanova` [ста́нова] | `pet stanova` [пэт ста́нова] |
| `grad` [град] | `gradova` [гра́дова] | `mnogo gradova` [мно́го гра́дова] |
| `jaje` [я́е] | `jaja` [я́я] | `pet jaja` [пэт я́я] |
| `prijatelj` [при́ятэль] | `prijatelja` [при́ятэля] | `malo prijatelja` [ма́ло при́ятэля] |

Правило, которое держит почти всё:

- **ж. на -a** — окончание **-a** (долгое, на письме то же): `kuća` [ку́ча] → `kuća` [ку́ча]
- **ср.** — **-a**: `jaje` [я́е] → `jaja` [я́я]
- **м. короткое** (один слог) — **-ova / -eva**: `stan` [стан] → `stanova` [ста́нова], `ključ` [ключ] → `ključeva` [клю́чэва]
- **м. длинное** — **-a**: `dinar` [ди́нар] → `dinara` [ди́нара]
- **прилагательное** — всегда **-ih**: `novih` [но́вих], `velikih` [вэ́ликих], `dobrih` [до́брих]: `pet velikih soba` [пэт вэ́ликих со́ба], `mnogo novih knjiga` [мно́го но́вих кни́га]

> Когда сомневаешься — говори на «пакетах»: `pet dinara`, `pet minuta`, `pet godina` — они почти всегда нужны.
