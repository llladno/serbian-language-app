## Части тела

| Сербский | Русский |
|---|---|
| `glava` [гла́ва] | голова |
| `grlo` [гр́ло] *(грло)* | горло |
| `stomak` [сто́мак] *(стомак)* | живот, желудок |
| `zub` [зуб] | зуб |
| `leđa` [лэ́дьжа] *(леђа — спина)* | спина |
| `ruka` [ру́ка] | рука |
| `noga` [но́га] | нога |

> `leđa` — только множественное число, как русские «брюки»: нельзя
> сказать «одно леђо».
