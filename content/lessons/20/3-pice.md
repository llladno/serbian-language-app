## Напитки

| Сербский | Русский |
|---|---|
| `voda` [во́да] *(вода)* | вода *(`gazirana` [гази́рана] / `negazirana` [негази́рана] — с газом / без)* |
| `kafa` [ка́фа] *(кафа)* | кофе |
| `čaj` [чай] *(чај)* | чай |
| `sok` [сок] *(сок)* | сок |
| `pivo` [пи́во] *(пиво)* | пиво |
| `vino` [ви́но] *(вино)* | вино *(`crno` [црно] / `belo` [бе́ло] — красное / белое)* |
| `rakija` [ра́кия] *(ракија)* | ракия — фруктовая водка, сербский аперитив |

- `Jednu kafu, molim.` [е́дну ка́фу, мо́лим.] *(једну кафу — один кофе,
  пожалуйста)*
- `Za mene sok.` [за ме́не сок.] *(за мене — мне сок)*
- `Još jedno pivo.` [ёш е́дно пи́во.] *(још једно — ещё одно пиво)*
