## Слова-противоположности

Учим тройками **м. / ж. / ср.** — сразу с родом:

| | м. | ж. | ср. |
|---|---|---|---|
| красивый / некрасивый | `lep` [лэп] / `ružan` [ру́жан] | `lepa` [лэ́па] / `ružna` [ру́жна] | `lepo` [лэ́по] / `ružno` [ру́жно] |
| молодой | `mlad` [млад] | `mlada` [мла́да] | `mlado` [мла́до] |
| высокий | `visok` [ви́сок] | `visoka` [ви́сока] | `visoko` [ви́соко] |
| чистый / грязный | `čist` [чист] / `prljav` [пр́ляв] | `čista` [чи́ста] / `prljava` [пр́лява] | `čisto` [чи́сто] / `prljavo` [пр́ляво] |
| тёплый / холодный | `topao` [то́пао] / `hladan` [хла́дан] | `topla` [то́пла] / `hladna` [хла́дна] | `toplo` [то́пло] / `hladno` [хла́дно] |
| быстрый / медленный | `brz` [брз] / `spor` [спор] | `brza` [бр́за] / `spora` [спо́ра] | `brzo` [бр́зо] / `sporo` [спо́ро] |
| дешёвый / дорогой | `jeftin` [е́фтин] / `skup` [скуп] | `jeftina` [е́фтина] / `skupa` [ску́па] | `jeftino` [е́фтино] / `skupo` [ску́по] |
| хороший / плохой | `dobar` [до́бар] / `loš` [лош] | `dobra` [до́бра] / `loša` [ло́ша] | `dobro` [до́бро] / `loše` [ло́шэ] |

Три «подводных камня»:

- **Беглое `a`.** В мужском роде перед последней согласной стоит `a`, которого нет в женском и среднем: `ružan → ružna`, `hladan → hladna`, `dobar → dobra`. И `topao → topla`, `beo → bela`.
- После **š, č, ž** в среднем роде бывает `-e`, а не `-o`: `loše` [ло́шэ].
- `skupo` и `jeftino` ты уже знаешь как слова «дорого / дёшево» из урока про транспорт — это среднеродовая форма.

`Kafa je skupa.` [Ка́фа е ску́па.] *(Кофе дорогой.)* `Hleb je jeftin.` [Хлэб е е́фтин.] *(Хлеб дешёвый.)*
