## Глагол «быть» — `jesam` [е́сам]

По-сербски «я студент» **нельзя** сказать без глагола. Всегда нужен
короткий глагол `sam / si / je / smo / ste / su` [сам / си / е / смо / стэ / су]:

| | утверждение | отрицание |
|---|---|---|
| **ja** (я) | **sam** | **nisam** |
| **ti** (ты) | **si** | **nisi** |
| **on / ona / ono** (он / она / оно) | **je** | **nije** |
| **mi** (мы) | **smo** | **nismo** |
| **vi** (вы) | **ste** | **niste** |
| **oni / one / ona** (они: м. / ж. / ср.) | **su** | **nisu** |

- `Ja sam iz Rusije.` [я сам из ру́сие] *(я из России)*
- `Ti si student?` [ти си сту́дэнт?] *(ты студент?)*
- `Ana je iz Srbije.` [а́на е из ср́бие] *(Ана из Сербии)*
- `On nije odavde.` [он ни́е о́давдэ] *(он не отсюда)*
- `Mi smo iz Rusije.` [ми смо из ру́сие] *(мы из России)*
- `Vi ste iz Srbije?` [ви стэ из ср́бие?] *(вы из Сербии?)*
- `Oni su iz Srbije.` [о́ни су из ср́бие] *(они из Сербии)*

> `sam / si / je / smo / ste / su` [сам / си / е / смо / стэ / су] —
> безударные и **не могут стоять первыми** в предложении.
