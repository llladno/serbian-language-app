## Глагол «быть» — `jesam` [е́сам]

По-сербски «я студент» **нельзя** сказать без глагола. Всегда нужен
короткий глагол `sam / si / je` [сам / си / е]:

| | утверждение | отрицание |
|---|---|---|
| **ja** (я) | **sam** | **nisam** |
| **ti** (ты) | **si** | **nisi** |
| **on / ona** (он / она) | **je** | **nije** |

- `Ja sam iz Rusije.` [я сам из ру́сие] *(я из России)*
- `Ti si student?` [ти си сту́дент?] *(ты студент?)*
- `Ana je iz Srbije.` [а́на е из србие] *(Ана из Сербии)*
- `On nije odavde.` [он ни́е о́давде] *(он не отсюда)*

> `sam / si / je` [сам / си / е] — безударные и **не могут стоять
> первыми** в предложении. Остальные формы (`smo` [смо], `ste` [сте],
> `su` [су]) — позже.
