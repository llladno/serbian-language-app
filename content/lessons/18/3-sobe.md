## Комнаты

| Сербский | Русский |
|---|---|
| `soba` [со́ба] *(соба)* | комната |
| `kuhinja` [кухи́ня] *(кухиња)* | кухня |
| `kupatilo` [купа́тило] *(купатило)* | ванная / туалет (обычно вместе) |
| `spavaća soba` [спа́вача со́ба] *(спаваћа соба)* | спальня |
| `dnevni boravak` [дне́вни бо́равак] *(дневни боравак)* | гостиная |
| `hodnik` [хо́дник] *(ходник)* | коридор, прихожая |
| `terasa` [те́раса] / `balkon` [ба́лкон] *(тераса / балкон)* | терраса / балкон |

- `Stan ima dve sobe.` [стан и́ма две со́бе.] *(стан има две собе — в
  квартире две комнаты)*
- `Kuhinja je mala, a dnevni boravak velik.` [кухи́ня е ма́ла, а
  дне́вни бо́равак ве́лик.] *(кухня маленькая, а гостиная большая)*

> «однушка / двушка» по-сербски — `garsonjera` [гарсоне́ра] /
> `dvosoban stan` [дво́собан стан].
