## Вещи в доме

| Сербский | Русский |
|---|---|
| `sto` [сто] *(сто)* | стол *(род. `stola` [сто́ла]; не путать со «sto» = 100)* |
| `stolica` [сто́лица] *(столица)* | стул *(⚠️ не «столица» — это `prestonica` [престо́ница])* |
| `krevet` [кре́вет] *(кревет)* | кровать |
| `orman` [о́рман] *(орман)* | шкаф |
| `frižider` [фрижи́дер] *(фрижидер)* | холодильник |
| `šporet` [шпо́рет] *(шпорет)* | плита |
| `sudopera` [судо́пера] *(судопера)* | раковина (кухонная) |
| `lampa` [ла́мпа] *(лампа)* | лампа |
| `polica` [по́лица] *(полица)* | полка |
| `ogledalo` [огле́дало] *(огледало)* | зеркало |

- `Na stolu je lampa.` [на сто́лу е ла́мпа.] *(на столу је лампа — на
  столе лампа)*
- `Frižider je nov.` [фрижи́дер е нов.] *(фрижидер је нов — холодильник
  новый)*
