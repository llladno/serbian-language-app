## koji / kakav / čiji

Три разных «какой» — меняются по роду (m / f / n):

| | вопрос | пример |
|---|---|---|
| `koji` / `koja` / `koje` | который (из ряда) | `Koji autobus ide u centar?` *(какой автобус)* |
| `kakav` / `kakva` / `kakvo` | какой (по качеству) | `Kakav je stan?` *(какая квартира?)* — `Velik i svetao.` |
| `čiji` / `čija` / `čije` | чей | `Čiji je ovo ključ?` *(чей это ключ?)* |

- `Koja je ovo ulica?` *(какая это улица?)*
- `Kakvo je vreme?` *(какая погода?)*
- `Čija je ovo torba?` *(чья это сумка?)*

> `koji` спрашивает выбор из известных вариантов, `kakav` — свойство.
