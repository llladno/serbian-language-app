## koji [ко́и] / kakav [ка́кав] / čiji [чи́и]

Три разных «какой» — меняются по роду (m / f / n):

| | вопрос | пример |
|---|---|---|
| `koji` [ко́и] / `koja` [ко́я] / `koje` [ко́е] | который (из ряда) | `Koji autobus ide u centar?` [ко́и а́утобус и́де у це́нтар?] *(какой автобус)* |
| `kakav` [ка́кав] / `kakva` [ка́ква] / `kakvo` [ка́кво] | какой (по качеству) | `Kakav je stan?` [ка́кав е стан?] *(какая квартира?)* — `Velik i svetao.` [ве́лик и све́тао.] |
| `čiji` [чи́и] / `čija` [чи́я] / `čije` [чи́е] | чей | `Čiji je ovo ključ?` [чи́и е о́во ключ?] *(чей это ключ?)* |

- `Koja je ovo ulica?` [ко́я е о́во у́лица?] *(какая это улица?)*
- `Kakvo je vreme?` [ка́кво е вре́ме?] *(какая погода?)*
- `Čija je ovo torba?` [чи́я е о́во то́рба?] *(чья это сумка?)*

> `koji` [ко́и] спрашивает выбор из известных вариантов, `kakav`
> [ка́кав] — свойство.
