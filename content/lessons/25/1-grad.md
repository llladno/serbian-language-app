## Город

| Сербский | Русский |
|---|---|
| `grad` *(град)* | город |
| `ulica` *(улица)* | улица |
| `trg` *(трг)* | площадь |
| `park` *(парк)* | парк |
| `centar` *(центар)* | центр |
| `pošta` / `banka` *(пошта / банка)* | почта / банк |
| `bolnica` / `apoteka` | больница / аптека |
| `pijaca` / `prodavnica` | рынок / магазин |
| `stanica` *(станица)* | остановка / станция |
| `autobus` *(аутобус)* | автобус |
| `most` / `reka` *(мост / река)* | мост / река |

- `Idem u centar autobusom.` *(еду в центр на автобусе)*
- `Pošta je na trgu.` *(почта на площади)*
