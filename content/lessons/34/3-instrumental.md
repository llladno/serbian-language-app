## Инструментал — «на чём», «с кем»

Помнишь `Idem u centar autobusom.` [И́дэм у цэ́нтар ау́тобусом.]
из городской темы? `autobusom` — это **инструментал**, падеж для «на
чём» / «с кем» / «чем». Для транспорта он главный способ сказать
«на автобусе, на поезде…». «С кем» говорят с предлогом `sa`:
`sa sestrom` [са сэ́стром] *(с сестрой)*.

Правило простое: к основе слова добавь `-om` (или `-em` после
`č/ć/š/ž/j/lj/nj`); у слов на `-a` и `-o` это окончание заменяет
последнюю букву:

| именительный | инструментал |
|---|---|
| `autobus` | `autobusom` |
| `voz` | `vozom` |
| `avion` | `avionom` |
| `auto` | `autom` |
| `bicikl` | `biciklom` |
| `sestra` | `sestrom` *(уже видел в уроке 31!)* |
| `taksi` | `taksijem` *(слово кончается на `-i` — между ними вставляется `j`)* |

- `Idem vozom.` [И́дэм во́зом.] *(еду на поезде)*
- `Letim avionom.` [Лэ́тим ави́оном.] *(лечу на самолёте)*
- `Vozim se biciklom.` [Во́зим сэ би́циклом.] *(катаюсь на велосипеде)*

> Без транспорта — просто наречием, без падежа: `Idem pešice.`
> [И́дэм пэ́шицэ.] *(иду пешком)*
