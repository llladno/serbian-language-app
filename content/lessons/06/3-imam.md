## У меня есть / нет — `imam / nemam` [и́мам / нэ́мам]

- `imam` [и́мам] *(имам — у меня есть)*
- `nemam` [нэ́мам] *(немам — у меня нет)*

Остальные лица — `imati` [и́мати] *(иметь)*; отрицание — тем же `ne-`
слитно:

| | есть | нет |
|---|---|---|
| **ja** (я) | **imam** | **nemam** |
| **ti** (ты) | **imaš** | **nemaš** |
| **on / ona / ono** | **ima** | **nema** |
| **mi** (мы) | **imamo** | **nemamo** |
| **vi** (вы) | **imate** | **nemate** |
| **oni / one / ona** | **imaju** | **nemaju** |

После них слово чуть меняет окончание (винительный / родительный
падеж). Пока запоминай готовыми формами:

| в словаре | после imam / nemam |
|---|---|
| brat | **Imam brata.** *(у меня есть брат)* |
| sestra | **Imam sestru.** |
| muž | **Imam muža.** |
| žena | **Imam ženu.** |
| sin | **Imam sina.** |
| ćerka | **Imam ćerku.** |
| dete → deca | **Nemam decu.** *(детей нет)* |

`mama` [ма́ма], `tata` [та́та] тоже меняются: `Imam mamu i tatu.`
[и́мам ма́му и та́ту.]
