## Дни недели

| Сербский | Русский |
|---|---|
| `ponedeljak` *(понедељак)* | понедельник |
| `utorak` *(уторак)* | вторник |
| `sreda` *(среда)* | среда |
| `četvrtak` *(четвртак)* | четверг |
| `petak` *(петак)* | пятница |
| `subota` *(субота)* | суббота |
| `nedelja` *(недеља)* | воскресенье |

`nedelja` — это и «воскресенье», и «неделя» вообще.
`vikend` *(викенд)* — выходные (суббота + воскресенье).

**«В какой-то день»** — `u` + винительный:

- `u ponedeljak` *(в понедельник)*, `u sredu` *(в среду)*, `u petak` *(в пятницу)*
- `za vikend` *(на выходных)*, `radnim danima` *(по будням)*
